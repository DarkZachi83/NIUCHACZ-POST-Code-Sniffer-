## Windows

1. Download **NIUCHACZ-…-windows-x64.zip** below and unpack it anywhere (e.g. `C:\NIUCHACZ`).
2. Run **NIUCHACZ.exe**. No Python needed.
3. Windows SmartScreen may warn about an unknown publisher (the program is not signed) – click *More info → Run anyway*.
4. Reports go to the `reports` folder next to the exe, settings to `config`.

The ESP32 firmware is in the `firmware` folder, the user manual in `docs` (MANUAL.md, INSTRUKCJA.md).
Tested mainly on Arch Linux – **Windows feedback is very welcome** (Issues).

## Windows (PL)

1. Pobierz poniżej **NIUCHACZ-…-windows-x64.zip** i rozpakuj w dowolnym miejscu (np. `C:\NIUCHACZ`).
2. Uruchom **NIUCHACZ.exe**. Python nie jest potrzebny.
3. Windows SmartScreen może ostrzec o nieznanym wydawcy (program nie jest podpisany) – kliknij *Więcej informacji → Uruchom mimo to*.
4. Raporty trafiają do folderu `reports` obok pliku exe, ustawienia do `config`.

Firmware ESP32 jest w folderze `firmware`, instrukcja obsługi w `docs`.
Program był testowany głównie na Arch Linux – **uwagi z Windowsa bardzo mile widziane** (Issues).
