# Narzędzia z czasów odczytu wyświetlacza / display-era tools

Skrypty diagnostyczne z pierwszej wersji NIUCHACZA, która czytała multipleksowany wyświetlacz
7-segmentowy karty (do 22.10.2026). Zostają jako dokumentacja drogi i do kart bez dostępnego zatrzasku.
Obecna metoda (zatrzask 74LCX374) ich nie potrzebuje – używaj `../latch_probe.py` i `../box_test.py`.

Diagnostic scripts from the first NIUCHACZ version, which read the card's multiplexed 7-segment display.
Kept for reference. The current latch-based method does not need them.
